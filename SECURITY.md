# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to [contact@arnobmahmud.com](mailto:contact@arnobmahmud.com). Do not disclose details in a public issue before the maintainer has had an opportunity to investigate.

Include the affected URL or version, a description of the issue, safe reproduction steps, and the potential impact. Do not include passwords, API tokens, personal information, or data belonging to other users. Use test data and avoid disruptive testing.

The maintainer will review reports as availability permits. There is no guaranteed response or remediation deadline. Please coordinate disclosure after a fix or mitigation has been evaluated.
